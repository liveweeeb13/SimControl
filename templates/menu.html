Quick Start

SimControl turns your device into a button controller for simulators.

Creating Buttons

  1. Click "🎛️ Edit Buttons" to configure your controller
  2. Select a position (1-35) on the grid
  3. Fill in the Title, Label and select a Key
  4. Click "Save" to create the button
  5. Click "Start SimControl" to launch your controller

Button Settings

  • Title: Internal name for organization
  • Label: Text/emoji displayed on the button
  • Key: Keyboard key sent on press
  • Toggleable: Button stays pressed (ON) or momentary (OFF)
  • Colors: Colors for OFF and ON states
  • Hold Time (toggleable: true): How long the key is held (milliseconds)

Automatic Rules

Rules let you automate button behavior:

  • Autodisable: Automatically disables target buttons when a trigger button changes state
  • Lock: Blocks interaction with target buttons based on a trigger button's state (FREEZE)

Creating Rules

  1. Click "⚙️ Edit Rules"
  2. Choose "+ Add Autodisable" or "+ Add Lock"
  3. Select the trigger button (1-35)
  4. Select the target buttons
  5. Choose the condition: "on" or "off"

Examples

  • Autodisable: Button 1 (Battery) disables buttons 2,3 when "off"
  • Lock: Button 1 (Master) blocks buttons 4,5,6 when "off"
